## 🥦 About

**Grocify** is a full-featured online grocery shopping web application built with React 19 and Vite. It offers a sleek, mobile-friendly UI with smooth navigation, product carousels, and a clean shopping experience — all running lightning-fast thanks to Vite's optimized build system.

---

## ✨ Features

- 🛍️ **Product Browsing** — Browse fresh groceries across multiple categories
- 🎠 **Interactive Carousels** — Smooth product sliders powered by Swiper.js
- 🔀 **Client-Side Routing** — Seamless page transitions with React Router
- 📱 **Responsive Design** — Optimized for all screen sizes — mobile, tablet, and desktop
- ⚡ **Blazing Fast** — Instant HMR (Hot Module Replacement) during development via Vite
- 🎨 **Modern UI** — Clean and intuitive interface with React Icons

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- **Node.js** — v18 or higher
- **npm** — v9 or higher (comes with Node.js)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/mohittiwari98/mohitgrociery-website.git
   cd mohitgrociery-website
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start the development server**

   ```bash
   npm run dev
   ```

4. **Open in your browser**

   ```
   http://localhost:5173
   ```
